Put the built shader bundles here (isorimshaders, and isorimshaders_mac / isorimshaders_linux for
those systems) to switch on exact LUT colour grading. See the main README, section "Exact colour
grading". Without them the colour looks still work, using the built-in blend.

The Waylith folder holds the mod's own GLSL shaders for RimWorld 1.7, which runs on the Waylith
engine instead of Unity. They are part of the mod and must stay where they are; the game compiles
them itself. See DEVELOPMENT.txt, "RIMWORLD 1.7 AND THE WAYLITH ENGINE".
